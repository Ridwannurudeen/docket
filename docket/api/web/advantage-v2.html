Specifications, runs, and what history establishes.

Each experiment carries a hashed specification — its metric as a formula, its null baselines and the argument for each, how many runs were planned, when they would stop, and the result that would refute the claim. Every run record cites that hash. The registration provenance beside each experiment says separately whether git establishes that the specification predates the run or whether that ordering is self-attested.

One of the three claims is refuted by its own falsifier. It is named in the first paragraph of the summary rather than left for a reader to find, and the experiment behind it is served here in full beside the two that survived. A registered claim that fails and says so is the result this report was built to be able to publish.

The same report as data: /advantage/v2.json every registration, every trial, every null and every falsifier result.

This does not replace v1

v1 is still here, and its figures have not moved

The first report — three tasks, each run once by hiring an agent and once by hand — is served at /advantage and /advantage.json. Its JSON is byte for byte as it was and not one of its figures has changed. Its page has changed in exactly one way: it now carries a link to this one, because a report nobody can reach from where they landed is a report nobody reads. It is the prior version of this page and not a superseded one, and nothing here rewrites it.

The human arm lives there, and it is n=1

v1 holds the only comparison against a person in this build, performed by hand, once. Nothing on this page compares an agent to a human: the repeated trials here are measured against computed null baselines, and no human arm was simulated to stand in for one.

What each is for

v1 answers what one hire and one person each did on one task. This page answers how far a figure moves across many observations, what a null baseline gets for free, and whether each registered claim survived contact with the data.

What was measured, and what was not

Every run is published, including the failures
A failed trial keeps its place in the denominator and is never re-run until it passes. All nine security scan failures were identical HTTP 429 rate limits; they are shown where they happened and counted as failed trials rather than as detections a scanner missed. Every aggregate on this page has the runs it came from underneath it.
Every rate carries its two counts
Numerator and denominator, in that order, with the share after them rather than instead of them. A rate over no observations reports null, because an arm that never spoke has a precision nobody measured and the division that would score it 1.0 is the flattering arithmetic this shape exists to refuse.
Null baselines are computed, not asserted
Each null is a function in the repository, run over the same data through the same scorer, and served beside the agent figure it qualifies. Flagging everything scores a recall of 1 and a precision of exactly the corpus base rate; a figure is only evidence of discrimination in as much as it sits above that line.
The falsifiers are evaluated, not restated
Each registered falsifier is checked clause by clause against the measured figures, and each clause carries what was observed. The word for a clause that fired is refuted; it is a statement about one registered sentence and the numbers it met, and not a verdict about an agent.
No transaction was sent, anywhere in this build
The grid experiment is a replay of a committed plan against prices that had already closed. Nothing was signed, submitted or held, no arm touched a chain, and the record says so in its own first sentence and again on each of its three arms.
What is absent, by name
Realized LP economics, net profit and loss over a window, and intervention latency are not here. Each needs capital deployed and transactions this build has never sent, so they are named as missing rather than approximated.
