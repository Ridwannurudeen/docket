The grid replay fired 0 of 5 buy levels across 744 candles, so its claim failed its own falsifier; this report tests six frozen experiments, not agent performance in general.

Each experiment carries its hashed specification, computed null baselines, every run, and registration provenance. What was measured, and what was not

Inspect the measurement rules and limits
Every run is published, including the failures
A failed trial keeps its place in the denominator and is never re-run until it passes. Every failed security scan in both dated runs was an HTTP 429 rate limit; each is shown where it happened and counted as a failed trial rather than as a detection miss. Every aggregate on this page has the runs it came from underneath it.
Every rate carries its two counts
Numerator and denominator, in that order, with the share after them rather than instead of them. A rate over no observations reports null, because an arm that never spoke has a precision nobody measured and the division that would score it 1.0 is the flattering arithmetic this shape exists to refuse.
Null baselines are computed, not asserted
Each null is a function in the repository, run over the same data through the same scorer, and served beside the agent figure it qualifies. Flagging everything scores a recall of 1 and a precision of exactly the corpus base rate; a figure is only evidence of discrimination in as much as it sits above that line.
The falsifiers are evaluated, not restated
Each registered falsifier is checked clause by clause against the measured figures, and each clause carries what was observed. The word for a clause that fired is refuted; it is a statement about one registered sentence and the numbers it met, and not a verdict about an agent.
No transaction was sent, anywhere in this build
The grid experiment is a replay of a committed plan against prices that had already closed. Nothing was signed, submitted or held, no arm touched a chain, and the record says so in its own first sentence and again on each of its three arms.
What is absent, by name
Realized LP economics, net profit and loss over a window, and intervention latency are not here. Each needs capital deployed and transactions this build has never sent, so they are named as missing rather than approximated.
