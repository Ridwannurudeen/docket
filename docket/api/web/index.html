What answered, and what only claimed to.

Docket reads the ERC-8004 agent registry on BNB Smart Chain, asks every endpoint an agent declared whether anything answers there, and publishes exactly what it saw.

It does not rate, rank or vouch for any agent. Each figure below is stated inside the snapshot and sample size it was counted in, because a count without its population cannot be read.

How to read this

Coverage travels with the number

Every response carries the snapshot it was counted in, how many agents were stored, and how many the registry said to expect. When those two disagree, the page says so at the top and every count below understates its population.

Declared is not observed

An agent declaring an A2A or MCP endpoint is a claim it made about itself on chain. Whether a host answers there is a separate measurement, and the two are never added together.

One attempt, one moment

Liveness is a single GET per endpoint, at the moment of the sweep. A failure is one observation, not a pattern — and an answer is not evidence that the agent behind the URL does anything.
