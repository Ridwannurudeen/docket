Vocabulary for this report

Read the eight definitions
Arm
One side of the comparison: agent or human/manual.
Primary
One scheduled attempt on one case by one arm; no scored retry.
Seat
A fixed model evaluator of anonymised outputs. Both seats are run by one operator, so they are prompt-blinded but not independent evaluators.
Input lock
The point when the exact cases and their hashes are fixed; no case can then be removed or replaced.
Frozen label
The hostile/benign answer fixed before evaluation and used by read-only diagnostics.
Falsifier
A condition written in advance that would refute the bounded claim if it fired.
complete_unscored
Every scheduled attempt ended, but required scoring artifacts are absent, so rubric quality and the registered falsifier remain unavailable.
superseded_before_input_lock
A later registration replaced the family before exact inputs were locked; neither arm ran.

What happened in the completed Warden family

Fixed in advance: the questions, exact-input locking rule, arm order, clocks, failure treatment, scoring process, and falsifier.

Run: 12 planned agent-versus-manual pairs, or 24 primaries. Warden recall was 4/8 (0.50) versus the human's 6/8 (0.75), with three Warden critical failures.

Went wrong: 23 primaries succeeded. Manual w4-ho-01 failed with ledger state invoke_error / JSONDecodeError. Seat B returned no first scoring response, and retry or substitution is forbidden.

Meaning: one manual primary failed and rubric quality is permanently unscored. The family is complete_unscored, not a scored performance result.

Three additive reports

These reports are additive; none supersedes another. They answer different questions and remain reachable together.

Compare the three report roles

v1

v1 is the original paired eligibility artifact at n=1. It records one hired arm and one manual arm for each task, with both outputs in full.

v2

v2 is agent-versus-computed-null armour with no human arm. It publishes repeated trials, computed nulls, registration provenance, and evaluated falsifiers.

v3

v3 is the pre-registered paired evaluation scored by two prompt-blinded model seats run by one operator. It compares agent and manual arms over frozen inputs when those inputs and outputs exist.

How to read the state

Inspect the reconstruction method

When reconstruction succeeds, the state is derived rather than typed into this shell. A missing input digest stops at registration. A locked input with no claimed primary stops before running. Ledger events move a family through work in progress and terminal-but-unscored states. Only durable sheets plus the published A/B mapping permit the registered falsifier checks to produce either terminal claim state. If reconstruction fails, the report area says so instead of presenting zero families.
